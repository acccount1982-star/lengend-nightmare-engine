# Changelog

All notable changes to Lengend Nightmare Engine are documented here.

## [0.1.0] — 2026-09-13

### Added

- Deterministic turn-based campaign simulation with seeded randomness.
- Fixed-timestep real-time arena simulation with movement, bounds, inputs, and collision hooks.
- Shared `HybridGameEngine` facade for both simulation modes.
- Versioned save serialization, validation, and legacy migration.
- Sync and async client storage adapters.
- TypeScript declarations, MIT license, examples, and engine tests.

The package is ready for a first GitHub release once the remote repository is connected.
